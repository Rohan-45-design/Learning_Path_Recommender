# Skill: Deep Learning

## Description
Deep Learning encompasses artificial neural networks inspired by biological brain structures, utilizing layered representation learning to model complex data patterns in vision, text, and speech.

## Core Concepts
- Artificial Neurons & Activation Functions (ReLU, Sigmoid, Softmax)
- Forward Pass & Loss Functions
- Backpropagation Calculus & Chain Rule Gradient Updates
- Optimizers: SGD, Adam, AdamW
- Frameworks: PyTorch, TensorFlow

## Prerequisites
- Python
- Machine Learning

## Category
AI Advanced

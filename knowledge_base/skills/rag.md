# Skill: Retrieval-Augmented Generation (RAG)

## Description
Retrieval-Augmented Generation combines external vector similarity search with Generative Large Language Models to provide grounded, domain-specific, anti-hallucinatory AI answers.

## Core Concepts
- Dense Vector Embeddings & Indexing (ChromaDB, FAISS)
- Metadata Filtering & Topological Skill Gap Reranking
- Context Window Construction (`LEARNER PROFILE` + `RELEVANT LEARNING RESOURCES`)
- Strict Anti-Hallucination Prompt Engineering & Citation Tracking

## Prerequisites
- LLM
- Python
